# achievement-lab

A playground for GitHub **profile achievements** — nothing here is production code.

Every file in 
otes/ is a throwaway commit used to exercise a specific
GitHub achievement flow:

| Flow | What it is for |
| --- | --- |
| 
otes/scratch-*.md | pull requests opened and merged inside this repo (Pull Shark / YOLO territory) |
| 
otes/coauthored-*.md | a commit carrying Co-authored-by: trailers (Pair Extraordinaire territory) |
| Discussions | questions and answers, including accepted answers (Galaxy Brain territory) |

The repository is public on purpose: achievements only count activity that
other people can see. Nothing here is a real feature, and no pull request in
this repository is ever meant to be reviewed by anyone.

* Created by the account owner, for the sole purpose of exercising GitHub's
  own achievement system.
